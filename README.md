# DEADLOCK

Python / Higumaによる、近未来の心理戦カードバトル。全8種類のカードを使い、行動を伏せて同時に公開します。

## 起動

Python 3.12以上をインストールし、Windows PowerShellで次を実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

ブラウザで http://127.0.0.1:8000 を開きます。

右上の月／太陽ボタンでライト・ダークを切り替えられます。初期表示はOS設定に従い、選んだテーマは次回も保持されます。手札は最大4列で折り返し、選んだカードの効果を下に表示します。

射撃・カウンター・貫通射撃・ドレイン・エネルギーブレイクの対象は、相手の戦闘員をタップして選べます。対象欄からの選択も可能です。スマホのアリーナでは相手一覧を横にスワイプできます。「設定」メニューに音とログアウトがあります。

公開済みの行動と戦績の対戦履歴は、戦闘員の画像・使用カードの画像・対象・受けたダメージ・回復効果・残りHP・残りEN・消費EN・EN変化を並べて表示します。残り10秒未満で未準備の場合は通知が表示され、準備完了すると消えます。音ONなら通知開始時に一度鳴ります。観戦者・脱落者・結果公開中は通知されません。

全員の準備完了後、公開された結果に合わせてカードが飛び、着弾・防御・反撃・HP回復・EN変化を表示します。貫通はPIERCE、シールドはBLOCK、指定相手の反撃はCOUNTERで区別。決着はVICTORY・DEFEAT・DRAWの大きな表示、観戦者はBATTLE OVER。ランクの途中の決着にはBATTLE RESULTと表示し、試合全体の結果と区別します。多人数戦で途中脱落した場合もDEFEATを表示し、その後は観戦を続けられます。

決着演出は約5秒で自動的に閉じ、「結果を見る」またはEscでも閉じられます。画面を移動した場合や再戦時には演出を終了。音は初期OFFで、ONにした場合だけ短い発動音と決着音が鳴ります。「戦闘員」の「演出を減らす」、またはOSの動きを減らす設定で、飛ぶカードや拡大を省き、静止した表示に切り替えます。伏せたカードの選択中には演出を出さず、再接続時に過去の攻撃を再生しません。

環境ダメージはカード選択の上に専用の警告枠で表示します。開始までのラウンド数、全員へのHPダメージ、防御不可、次の増加を確認できます。自分のHPが環境ダメージ以下になると脱落注意を表示。発動通知と対戦履歴では、カードダメージと環境ダメージを分けて表示します。「演出を減らす」がONでも案内は残ります。

見出し・数字はOxaniumとZen Kaku Gothic Newの見出し用サブセットを自己配信します。本文は端末の日本語フォントです。書体とSIL Open Font Licenseをstatic/fontsに同梱し、プレイ中の外部フォント接続はありません。

開発時はrequirements-dev.txtを導入して自動テストを実行します。

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
.\.venv\Scripts\python.exe -m pytest -q
```

## 遊び方

1. 登録またはゲスト参加。登録した場合は復旧コードを保管します。
2. アリーナで部屋名・合言葉・定員を設定して作成します。
3. 他のユーザーが合言葉を入力して参加し、部屋主が開始します。
4. 最大50秒以内にカードと必要な対象を選び、カードを伏せて準備完了します。準備完了までは変更可能。全員が準備完了するとすぐに効果が発動します。
5. 最後の生存者が勝利。結果画面から再戦できます。

別ユーザーのローカル検証には別ブラウザ、別プロファイル、プライベートウィンドウを使います。同じブラウザの通常タブはアカウントを共有します。

## モード・判定

- アリーナ：2〜6人の個人戦。合言葉だけで参加。対戦中の参加者は観戦、次の試合からプレイします。
- ランク：正式アカウントのみ、自動マッチングの1対1、2本先取。引き分けのバトルも含め最大5バトル。2勝に届かなければ試合は引き分け。
- 標準は初期HP15・EN0、EN上限4。アリーナの部屋作成・待機中・終了後の部屋設定で初期HP1〜100（回復上限）・初期EN0〜4・使用カード1種類以上を設定できます。初期ENで使えるカードが必要です。ランクは初期HP15。同じカードは連続使用できません。
- 射撃：2ダメージ。シールド：射撃・ドレインを防ぐ。カウンター：指定相手から自分への射撃・ドレイン・貫通射撃を防ぎ2反撃。チャージ：エネルギー+2。貫通射撃：エネルギー2消費、3ダメージ、シールド不可・カウンター可能。
- ヒール：EN2消費、HP+3。ドレイン：EN2消費、相手に2ダメージ、自分を1回復。射撃と同様に防御・反撃できますが回復は成立します。エネルギーブレイク：EN1消費、相手のEN−2、防御・反撃不可。
- 回復とダメージの合計を同時にHPへ反映し、回復上限は部屋の初期HP。EN減少カードのコストを払い、チャージを反映して上限4に収めた後、EN減少を同時に反映。その後の残りENで他のカードのコストを判定し、足りなければ効果なし・コスト消費なしの発動失敗です。チャージ分もEN減少の対象。EN0からのチャージ＋ブレイクはEN0、EN4からなら上限4の後に減ってEN2です。失敗したカードも連続使用不可です。結果公開は5秒、選択時間は最大50秒です。
- 全行動を同時に判定。そのラウンドに倒された人の攻撃・チャージも成立します。反撃はさらに反射されません。
- 7ラウンド目から全員へ防御不可の環境ダメージ。R7〜11は1、R12〜16は2、R17〜21は3、以後5ラウンドごとに1増加。回復とチャージだけでも必ず終了します。現在の最大回復量で、初期HP15では遅くともR31、カスタムHP100でもR51までに1バトルが終了します。
- 対戦画面上部に降参ボタンがあります。確認画面では最初に「対戦を続ける」を選択。確定するとアリーナでは脱落・観戦、ランクでは2本先取の試合全体が敗北となり、戦績とレートに反映します。
- 準備完了せず時間切れになると選択中のカードを使用します。未選択、または必要な対象が未選択なら無操作。連続2回の未操作で脱落。使用可能なカードがないときは「無操作で準備完了」を押せます。この操作は未操作扱いになりません。切断時も時間は進みます。
- 全員同時脱落は引き分け。同じラウンドの脱落者は同順位。
- 公開情報はHP・エネルギー・直前のカード・公開済み履歴。伏せた選択は本人以外へ送信しません。

追加カードの画像は組み込みimagegenで生成。既存のカード枠・紙の質感・手描き線を維持し、static/card-heal.png・card-drain.png・card-energy-break.pngを追加。プロンプトはoutput/card-art-prompts.mdに記録しています。

## ランク

初期1000、5試合の配置戦後にランク表示。ブロンズ0〜799、シルバー800〜1099、ゴールド1100〜1399、プラチナ1400〜1699、ダイヤモンド1700以上。

期待勝率 E = 1 / (1 + 10 ** ((相手レート - 自分レート) / 400))。
変動 = 四捨五入(32 * (S - E))。勝利1、引分0.5、敗北0。下限0、試合全体で一度更新。勝利本数による補正なし。

許容差は0秒±100、15秒±200、30秒±300、60秒±400。双方の許容範囲内で近いレート、同差では待機が長い相手を優先。60秒後に本人が制限解除できます。10秒の承認画面を経て開始。未承認の場合、承認済みユーザーは元の待機時間を引き継ぎます。直近相手と5分間再マッチなし。BOT・指定相手の対戦によるレート更新はありません。

## アカウント・チャット

メールなし。IDは非公開、表示名と公開識別番号を表示。パスワード・復旧コードはscryptでハッシュ化、セッション識別子はSHA-256でDB保存。復旧で旧コードと全ログインを無効化。ゲストからの登録は同じユーザーIDと部屋を引き継ぎます。

ウィスパーは同じ部屋の送受信者にだけ返します。観戦者・脱落者の会話は対戦中の生存者へ返しません。ブロック・連投制限・通報あり。通信はWebSocketで1秒ごとに本人向け状態を同期し、失敗時はHTTPへフォールバックします。

戦闘員は8種類。従来の5体に女の子のメカニック・パイロット・メディックを追加し、既存の手描き線・紙・色使いを維持しています。追加画像は組み込みimagegenで生成し。ランク章5段階は既存のstatic/atlas.pngから表示します。見た目による性能差はありません。

## 運用・公開

Cloudflare Quick Tunnelで、起動している間だけ友達に公開できます。cloudflaredをPATHから実行できる環境が必要です。

```powershell
.\.venv\Scripts\python.exe app.py --d
# 8000が使用中なら別のポートを指定
.\.venv\Scripts\python.exe app.py --d --port 8003
```

専用環境を有効にしている場合は`python app.py --d`でも起動できます。`--tunnel`は`--d`と同じです。表示された`https://....trycloudflare.com`を共有し、公開URLからログイン・参加してください。HTTPS用Cookieは自動で有効になります。`Ctrl+C`でトンネルと、このコマンドが起動したゲームサーバーを終了します。既存のサーバーは停止しません。

URLは起動ごとに変わり、Cloudflareアカウントは不要です。Quick Tunnelは開発・友達との試遊向けです。固定URLでの継続公開には名前付きトンネルなど別の運用設定が必要です。公開中はURLを知る人がアクセスできます。既存のcloudflared設定によってQuick Tunnelが起動できない場合は、Cloudflareの案内を確認してください。この起動処理は認証情報や設定ファイルを変更しません。

- DEADLOCK_HOST：既定127.0.0.1。コンテナやLANでは0.0.0.0を指定します。
- DEADLOCK_PORT：既定8000。
- DEADLOCK_DB：SQLite保存先。公開時は永続ボリューム上のファイルを指定します。
- DEADLOCK_HTTPS：HTTPS公開では1を指定してCookieをSecureにします。ローカルHTTPでは未設定。
- 1プロセスが全対戦を管理します。複数プロセス・複数台へ分散してはいけません。
- 待機部屋・進行中の対戦・検索キュー・チャットはメモリ上。再起動で終了し、未完了試合のレートは変動しません。終了済み戦績とアカウントはDBに残ります。
- 待機中・終了済みで120秒以上応答のない参加者は退出し、無人の部屋は終了します。
- 実運用の負荷・公開HTTPS・実端末での長時間対戦は別途検証が必要です。現在は小規模単一サーバー構成です。
- 通報の確認と利用停止はサーバー管理者がローカルCLIで行います。

```powershell
.\.venv\Scripts\python.exe manage.py reports
.\.venv\Scripts\python.exe manage.py ban --user-id 対象の内部ID
.\.venv\Scripts\python.exe manage.py unban --user-id 対象の内部ID
```

対戦者の利用停止を適用する前に対象を確認してください。解除はunban、利用停止時のログインは失効します。
